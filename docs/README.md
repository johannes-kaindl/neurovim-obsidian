# NeuroVim — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something and fixing something are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first finished mission.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Turn on Vim mode, start mission M-01, fix the transmission, submit. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "Mission paused — Vim restored.", "Signal lost. Check your uplink.", the missing UPLINK tab. |

The [README](https://github.com/johannes-kaindl/neurovim-obsidian/blob/main/README.md) covers what the plugin does, every setting, the CIPHER uplink and what is recorded.
